# Lumi ✦ — Гоо сайхны онлайн дэлгүүр

Монгол хэл дээрх, бүрэн ажиллагаатай гоо сайхны бүтээгдэхүүний онлайн дэлгүүр.

## Технологи

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4** — цэвэр цагаан + зөөлөн роз брэндийн загвар
- **Prisma 6** + **SQLite** (dev) — өгөгдлийн сан
- **Auth.js (NextAuth v5)** — бүртгэл/нэвтрэлт, нууц үг bcrypt-ээр хадгална
- **Zustand** — сагсны төлөв (localStorage-д хадгална)

## Боломжууд

- 🏠 Нүүр хуудас — hero, ангилал, онцлох бараа
- 🔍 Бараа жагсаалт — хайлт, ангилалаар шүүх, үнээр эрэмбэлэх
- 📄 Барааны дэлгэрэнгүй + төстэй бараа
- 🛒 Сагс — тоо өөрчлөх, устгах, хүргэлтийн тооцоо
- 💳 Захиалга — хүргэлтийн мэдээлэл, үлдэгдэл шалгах
- 👤 Хэрэглэгч — бүртгэл, нэвтрэлт, профайл, захиалгын түүх
- 🛠 Admin — бараа нэмэх/засах/устгах, захиалгын төлөв удирдах

## Эхлүүлэх

```bash
npm install          # багц суулгах (Prisma client автоматаар generate хийнэ)
npm run db:push      # өгөгдлийн сан үүсгэх
npm run db:seed      # жишээ өгөгдөл нэмэх
npm run dev          # http://localhost:3000
```

## Тушаалууд

- `npm run dev` — хөгжүүлэлтийн сервер
- `npm run build` — production build
- `npm run db:studio` — Prisma Studio (өгөгдлийн санг харах)
- `npm run db:seed` — өгөгдлийг дахин ачаалах

## Production-д гаргахад анхаарах

- `prisma/schema.prisma`-д provider-ийг `postgresql` болгож, Neon/Postgres холбоно
- `.env`-д `AUTH_SECRET`-ийг шинэ нууц утгаар солино
- Барааны зураг одоо `public/products/*.svg` (dev). Serverless дээр зургийн upload/URL ашиглах
- QPay төлбөрийн жинхэнэ холболт нэмэх (одоо checkout нь захиалга үүсгэхэд бэлэн)
